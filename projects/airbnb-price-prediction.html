Airbnb Price Prediction

This project modeled Airbnb listing prices using property, location, and listing attributes to estimate likely pricing ranges for major U.S. cities.

Project context

Pricing for rental listings depends on many factors: city, neighborhood, property type, room configuration, and listing attributes. This project built a model to help estimate price based on these variables and compare multiple predictive approaches.

Project information

  • Category: Machine Learning
  • Language: R
  • Models: Linear Regression, Random Forest, XGBoost
